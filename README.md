# ML Algorithms from Scratch

This repository contains custom implementations of two core machine learning algorithms built from scratch using only NumPy:

-  **XGBoost Regressor** – Gradient boosting tree-based model for regression
-  **K-Nearest Neighbors (KNN)** – For both regression and classification

No external ML libraries (like scikit-learn or XGBoost) were used — this is purely for learning and understanding how these models work under the hood.
