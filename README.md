# Machine Learning Algorithms from Scratch 🧠

A repository dedicated to demystifying core machine learning algorithms by building them from the ground up. The focus is on providing transparent, educational, and minimal-dependency implementations to understand their inner workings.

---

## 🚀 Models Implemented

This repository currently contains from-scratch implementations of the following algorithms:

### 1. XGBoost (Extreme Gradient Boosting) Regressor
A powerful and efficient implementation of the gradient boosting framework for regression tasks.

* **Implementations:**
    * `xgb_regressor.ipynb`: A Python implementation using **NumPy**, perfect for interactive learning in a Jupyter environment.
    * `xgb_regressor.cpp`: A C++ implementation demonstrating the core logic in a lower-level language for performance insights.

### 2. K-Nearest Neighbors (KNN)
A simple yet effective non-parametric algorithm that can be used for both regression and classification tasks.

* **Implementation:**
    * `knn.ipynb`: A Python implementation built with **NumPy**, illustrating the distance calculation and neighbor-finding logic.

---

## 🛠️ Core Philosophy

The primary goal of this project is to learn and teach. To achieve this, the implementations adhere to a key principle:

* **Minimal Dependencies:** The core logic is built using only **NumPy** to ensure we don't rely on "black box" libraries like Scikit-learn or the official XGBoost package. This forces a deeper understanding of the mechanics behind each model.

## ⚡ Getting Started

To explore the code and run the notebooks, follow these steps:

1.  Clone the repository to your local machine:
    ```bash
    git clone https://github.com/naveenthumati95/ml-algorithms-from-scratch.git
    ```
2.  Navigate into the cloned directory:
    ```bash
    cd ml-algorithms-from-scratch
    ```
3.  Open the `.ipynb` files in a Jupyter environment (like Jupyter Lab or VS Code) to see the models in action.
